마지막으로 Windows Server 2022 가상머신(w2k22-ad)을 생성하고 설치한다. 이후 w2k22-mem1, w2k22-mem2는 Clone으로 복제한다.

w2k22-ad 사양: CPU 1p2c / RAM 4096MB / HDD 60GB / NAT / IP 10.0.0.21

---

## 1. 새 가상머신 생성

**File → New Virtual Machine → Custom (advanced) → Next**
Hardware compatibility 기본값 유지 → Next
**"I will install the operating system later"** → Next

Guest OS: **Microsoft Windows**, Version: **Windows Server 2022** 를 선택한다.
![](/assets/images/VMware/WS22/5.png){: style="width:55%;" }<br>

VM 이름을 `w2k22-ad`로 입력하고 저장 위치를 지정한다.
![](/assets/images/VMware/WS22/6.png){: style="width:55%;" }<br>

Firmware Type은 **UEFI** 를 선택한다.
![](/assets/images/VMware/WS22/7.png){: style="width:55%;" }<br>

CPU: 1p2c → Next / Memory: **4096 MB** → Next / Network: **NAT** → Next

I/O Controller: **LSI Logic SAS** → Next
![](/assets/images/VMware/WS22/10.png){: style="width:55%;" }<br>

Disk Type: **NVMe** → Next
![](/assets/images/VMware/WS22/9.png){: style="width:55%;" }<br>

Create a new virtual disk → Next
디스크 크기: **60 GB**, single file → Next → Next → **Finish**
![](/assets/images/VMware/WS22/13.png){: style="width:55%;" }<br>

---

## 2. ISO 연결 및 설치 시작

**Edit virtual machine settings → CD/DVD (SATA) → Use ISO image file** 에서 Windows Server 2022 ISO 경로를 지정하고 OK → **Power on this virtual machine** 을 클릭한다.
![](/assets/images/VMware/WS22/17.png){: style="width:90%;" }<br>

설치 언어, 시간/화폐 형식, 키보드 모두 **한국어** 로 설정하고 다음을 클릭한다.
![](/assets/images/VMware/WS22/18.png){: style="width:75%;" }<br>

**지금 설치(I)** 를 클릭한다.
![](/assets/images/VMware/WS22/19.png){: style="width:75%;" }<br>

제품 키 입력 화면에서 **"제품 키 없음"** 을 클릭한다.

> 실습 환경이므로 제품 키 없이 설치를 진행한다.

![](/assets/images/VMware/WS22/20.png){: style="width:75%;" }<br>

운영 체제 선택에서 **Windows Server 2022 Datacenter (데스크톱 환경)** 를 선택하고 다음을 클릭한다.

> 데스크톱 환경 버전을 선택해야 GUI로 관리할 수 있다.

![](/assets/images/VMware/WS22/21.png){: style="width:75%;" }<br>

사용 조건에 동의 체크 후 다음을 클릭한다.
![](/assets/images/VMware/WS22/22.png){: style="width:75%;" }<br>

설치 유형은 **"사용자 지정: Microsoft 서버 운영 체제만 설치(고급)(C)"** 를 선택한다.
![](/assets/images/VMware/WS22/23.png){: style="width:75%;" }<br>

드라이브 0 할당되지 않은 공간(60GB)을 선택하고 다음을 클릭한다.
![](/assets/images/VMware/WS22/24.png){: style="width:75%;" }<br>

설치가 자동으로 진행된다.
![](/assets/images/VMware/WS22/25.png){: style="width:75%;" }<br>

설치 완료 후 Administrator 암호를 설정하고 **마침** 을 클릭한다.
![](/assets/images/VMware/WS22/26.png){: style="width:75%;" }<br>

## 3. 초기 설정

설치 완료 후 아래 항목들을 순서대로 설정한다.

3.1 컴퓨터 이름 변경

`실행(Win+R) → sysdm.cpl → 컴퓨터 이름 → 변경 → W2K22-tem 입력 → 확인 → 닫기 → 재시작`

> Clone 후 각 서버 이름을 변경할 것이므로 템플릿 단계에서는 tem으로 설정한다.

3.2 VMware Tools 설치

`VMware 메뉴 → VM → Reinstall VMware Tools... → 내 PC → VMware Tools 클릭 → Next → Typical → Next → Install → Finish → No`

> 클립보드 공유, 화면 해상도 자동 조정 등 편의 기능을 사용하려면 VMware Tools 설치가 필요하다.

3.3 방화벽 - ICMP 허용

`실행(Win+R) → control → 범주 → 작은 아이콘 → Windows Defender 방화벽 → 고급 설정 → 인바운드 규칙 → 파일 및 프린터 공유(에코 요청 - ICMPv4-In) → 사용함으로 변경`

> 기본값은 ping 요청을 차단한다. 허용해야 네트워크 연결 테스트가 가능하다.

3.4 전원 옵션 - 절전 모드 해제

`실행(Win+R) → control → 모든 제어판 항목 → 전원 옵션 → 균형 조정(권장) 설정 변경 → 디스플레이 끄기 및 컴퓨터를 절전 모드로 설정: 해당 없음 → 변경 내용 저장`

> 실습 중 서버가 절전 모드로 전환되면 서비스가 끊긴다.

3.5 Windows Update 비활성화

`실행(Win+R) → services.msc → Windows Update → 일반 → 시작 유형: 사용 안 함 → 중지 → 로그온 → 계정 지정 → 찾아보기 → 고급 → 지금 찾기 → Guest → 확인 → 확인 → 암호: It1 → 확인`

> 백그라운드 업데이트가 실행되면 실습 중 재부팅되거나 성능 저하가 발생할 수 있다. Guest 계정으로 변경해서 업데이트가 실질적으로 동작하지 못하게 막는다.

3.6 IP 설정

`실행(Win+R) → ncpa.cpl → Ethernet0 우클릭 → 속성 → 인터넷 프로토콜 버전 4(TCP/IPv4)`

- IP: `10.0.0.21`
- 서브넷 마스크: `255.255.255.0`
- 기본 게이트웨이: `10.0.0.254`
- DNS: `168.126.63.1`, `8.8.8.8`

---

## 4. VM 복제 (Clone)

w2k22-ad 설정이 완료되면 Clone으로 w2k22-mem1, w2k22-mem2를 만든다.

> Rocky Linux와 동일하게 우클릭 → Manage → Clone → Full clone 순서로 진행한다.

Clone 완료 후 각 VM을 부팅하고 아래와 같이 컴퓨터 이름과 IP를 변경한다.

| VM | 컴퓨터 이름 | IP |
|---|---|---|
| w2k22-ad | W2K22-AD | 10.0.0.21 |
| w2k22-mem1 | W2K22-MEM1 | 10.0.0.22 |
| w2k22-mem2 | W2K22-MEM2 | 10.0.0.23 |

---

이것으로 실습 환경 구성이 완료됐다.
Rocky Linux 3대, Windows 10, Windows 11, Windows Server 2022 3대까지 총 8대의 VM이 동일한 NAT 네트워크(10.0.0.0/24) 안에서 통신할 수 있는 상태가 됐다. 이후 포스트에서는 이 환경을 바탕으로 DHCP, DNS, 웹 서버, FTP 등 서비스 구축을 진행할 예정이다.
