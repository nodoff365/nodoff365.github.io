이전 포스트에서 NAT 네트워크 설정을 완료했다. 이번에는 Rocky Linux 9 가상머신을 생성하고 OS를 설치한 뒤, Clone 기능으로 rocky9-2, rocky9-3을 복제한다.

rocky9-1 기준 사양: CPU 1p2c / RAM 2048MB / HDD 50GB / NAT / IP 10.0.0.11

---

## 1. 새 가상머신 생성

VMware 메뉴에서 **File → New Virtual Machine...** 을 클릭한다.
![](/assets/images/VMware/Rocky9/1.png){: style="width:40%;" }<br>

**Custom (advanced)** 를 선택하고 Next를 클릭한다.

> Typical은 기본값으로 빠르게 생성되지만, 디스크 타입이나 컨트롤러 같은 세부 설정을 직접 지정하려면 Custom으로 진행해야 한다.

![](/assets/images/VMware/Rocky9/2.png){: style="width:55%;" }<br>

Hardware compatibility는 기본값(Workstation 25H2 or later)을 유지하고 Next를 클릭한다.
![](/assets/images/VMware/Rocky9/3.png){: style="width:55%;" }<br>

Guest OS 설치 방법은 **"I will install the operating system later"** 를 선택한다.

> ISO는 VM 생성 후 설정에서 연결할 것이다. 먼저 연결하면 VMware가 OS를 자동 감지해서 일부 설정을 임의로 변경할 수 있다.

![](/assets/images/VMware/Rocky9/4.png){: style="width:55%;" }<br>

Guest OS 종류는 **Linux**, Version은 **Rocky Linux 64-bit** 를 선택한다.
![](/assets/images/VMware/Rocky9/5.png){: style="width:55%;" }<br>

VM 이름을 `rocky9-1`로 입력하고 저장 위치를 지정한다.
![](/assets/images/VMware/Rocky9/6.png){: style="width:55%;" }<br>

프로세서 설정: Number of processors **1**, Number of cores per processor **2** → Next
![](/assets/images/VMware/Rocky9/7.png){: style="width:55%;" }<br>

메모리는 **2048 MB** 로 설정한다.
![](/assets/images/VMware/Rocky9/8.png){: style="width:55%;" }<br>

네트워크는 **Use network address translation (NAT)** 를 선택한다.
![](/assets/images/VMware/Rocky9/9.png){: style="width:55%;" }<br>

I/O Controller는 **LSI Logic (Recommended)** 를 선택한다.
![](/assets/images/VMware/Rocky9/10.png){: style="width:55%;" }<br>

Disk Type은 **SCSI** 를 선택한다.
![](/assets/images/VMware/Rocky9/11.png){: style="width:55%;" }<br>

**Create a new virtual disk** 를 선택한다.
![](/assets/images/VMware/Rocky9/12.png){: style="width:55%;" }<br>

디스크 크기는 **50 GB**, **Store virtual disk as a single file** 을 선택한다.

> Single file로 저장하면 디스크 파일 관리가 편하다. 여러 파일로 나누면 다른 PC로 복사할 때 번거롭다.

![](/assets/images/VMware/Rocky9/13.png){: style="width:55%;" }<br>

디스크 파일명은 기본값을 유지하고 Next → **Finish** 를 클릭한다.
![](/assets/images/VMware/Rocky9/14.png){: style="width:55%;" }<br>

설정 요약 화면에서 **Finish** 를 클릭한다.
![](/assets/images/VMware/Rocky9/15.png){: style="width:55%;" }<br>

## 2. ISO 연결 및 부팅

VM 생성 후 **Edit virtual machine settings** 를 클릭한다.
**CD/DVD (SATA)** 선택 → **Use ISO image file** 선택 후 Rocky Linux 9 minimal ISO 경로를 지정하고 OK → **Power on this virtual machine** 을 클릭한다.
![](/assets/images/VMware/Rocky9/16.png){: style="width:90%;" }<br>

부트 메뉴에서 **Install Rocky Linux 9.4** 를 선택한다.
![](/assets/images/VMware/Rocky9/17.png){: style="width:60%;" }<br>

---

## 3. Rocky Linux 설치

설치 언어는 **한국어** 를 선택하고 계속 진행(C)을 클릭한다.
![](/assets/images/VMware/Rocky9/18.png){: style="width:90%;" }<br>

설치 요약 화면에서 아래 항목들을 설정한다.

- **설치 목적지(D)**: 50GB 디스크 클릭 후 완료 (자동 파티션)
- **KDUMP**: 비활성화
- **root 비밀번호**: 설정
- **네트워크와 호스트 이름**: 아래에서 별도 설명

![](/assets/images/VMware/Rocky9/19.png){: style="width:90%;" }<br>

네트워크 설정에서 ens160을 선택하고 Configure를 클릭한다.
IPv4 Configuration을 **Manual**로 변경하고 아래와 같이 입력한다. (rocky9-1 기준)

- Addresses: `10.0.0.11/24`
- Gateway: `10.0.0.254`
- DNS servers: `168.126.63.1`, `8.8.8.8`
- **Automatically connect** 체크

![](/assets/images/VMware/Rocky9/20.png){: style="width:70%;" }<br>

모든 설정 완료 후 **설치 시작(B)** 을 클릭한다. 설치 완료 후 재부팅하면 된다.

## 4. SELinux 비활성화

재부팅 후 root로 로그인해서 SELinux를 비활성화한다.

> SELinux는 보안 정책 모듈인데, 실습 환경에서는 서비스 구성 중 예상치 못한 접근 제한이 발생할 수 있어 비활성화한다.

```bash
grubby --update-kernel ALL --args selinux=0
```

![](/assets/images/VMware/Rocky9/21.png){: style="width:50%;" }<br>

재부팅 후 `getenforce` 명령어로 SELinux 상태를 확인한다. **Disabled** 가 출력되면 정상이다.

```bash
getenforce
```

![](/assets/images/VMware/Rocky9/22.png){: style="width:35%;" }<br>

## 5. VM 복제 (Clone)

rocky9-1 설치가 완료되면 Clone으로 rocky9-2, rocky9-3을 만든다.

> 동일한 과정을 반복할 필요 없이 복제 후 IP만 변경하면 된다.

rocky9-1을 우클릭 → **Manage → Clone...** 을 선택한다.
![](/assets/images/VMware/Rocky9/23.png){: style="width:55%;" }<br>

Clone 마법사가 열리면 다음(N)을 클릭한다.
![](/assets/images/VMware/Rocky9/24.png){: style="width:60%;" }<br>

Clone from: **The current state in the virtual machine** 선택 → 다음(N)
![](/assets/images/VMware/Rocky9/25.png){: style="width:60%;" }<br>

Clone type: **Create a full clone** 선택 → 다음(N)

> Full clone은 원본과 완전히 독립된 복사본을 만든다. Linked clone은 원본 파일을 참조하기 때문에 원본이 없으면 동작하지 않는다.

![](/assets/images/VMware/Rocky9/26.png){: style="width:60%;" }<br>

VM 이름을 `rocky9-2`로 입력하고 저장 위치를 지정한 뒤 **마침** 을 클릭한다.
![](/assets/images/VMware/Rocky9/27.png){: style="width:60%;" }<br>

Clone 완료 후 **Close** 를 클릭한다. rocky9-3도 동일하게 반복한다.
![](/assets/images/VMware/Rocky9/28.png){: style="width:60%;" }<br>

Clone된 VM을 부팅한 후 IP를 변경한다. `nmtui` 명령어로 수정하면 된다.

- rocky9-2: `10.0.0.12`
- rocky9-3: `10.0.0.13`
