# TOC 스크롤 테스트

TOC가 길어질 때 우측 영역과 스크롤 동작을 확인하는 테스트 문서입니다.

## 1. 개요

긴 문서를 스크롤하면서 TOC 활성화, 하이라이트, 내부 스크롤바를 확인합니다.

## 2. 환경

- OS: Windows
- Runtime: Jekyll
- Theme: Custom

## 3. 체크 포인트

1. TOC 목록 길이 증가 시 내부 스크롤 생성
2. 본문 스크롤 시 활성 섹션 이동
3. 모바일 전환 시 TOC 배치 변경

## 4. 코드 예시 A

```bash
echo "toc test start"
for i in 1 2 3; do
  echo "section-$i"
done
```
