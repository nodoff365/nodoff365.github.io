이번 포스트에서는 클라이언트 PC 역할을 할 Windows 10 가상머신(w10-1)을 생성하고 설치한다.

w10-1 사양: CPU 1p2c / RAM 2048MB / HDD 50GB / NAT / IP 10.0.0.101

---

## 1. 새 가상머신 생성

**File → New Virtual Machine → Custom (advanced) → Next**
Hardware compatibility 기본값 유지 → Next
**"I will install the operating system later"** → Next

Guest OS: **Microsoft Windows**, Version: **Windows 10 x64** 를 선택한다.
![](/assets/images/VMware/Win10/5.png){: style="width:55%;" }<br>

VM 이름: `w10-1`, 저장 위치 지정 → Next

Firmware Type은 **BIOS** 를 선택한다.

> Windows 10은 BIOS와 UEFI 모두 가능하다. 실습 환경에서는 BIOS로 진행한다.

![](/assets/images/VMware/Win10/7.png){: style="width:55%;" }<br>

CPU: 1p2c → Next / Memory: **2048 MB** → Next / Network: **NAT** → Next

I/O Controller는 **LSI Logic SAS (Recommended)** 를 선택한다.
![](/assets/images/VMware/Win10/11.png){: style="width:55%;" }<br>

Disk Type: **NVMe** → Next → Create a new virtual disk → Next
디스크 크기: **50 GB**, single file → Next → Next → **Finish**

---

## 2. ISO 연결 및 설치 시작

**Edit virtual machine settings → CD/DVD (SATA) → Use ISO image file** 에서 Windows 10 ISO 경로를 지정하고 OK → **Power on this virtual machine** 을 클릭한다.
![](/assets/images/VMware/Win10/17.png){: style="width:90%;" }<br>

설치 언어, 시간/화폐 형식, 키보드 모두 **한국어** 로 설정하고 다음을 클릭한다.
![](/assets/images/VMware/Win10/18.png){: style="width:75%;" }<br>

**지금 설치(I)** 를 클릭한다.
![](/assets/images/VMware/Win10/19.png){: style="width:75%;" }<br>

운영 체제 선택에서 **Windows 10 Enterprise** 를 선택하고 다음을 클릭한다.
![](/assets/images/VMware/Win10/20.png){: style="width:75%;" }<br>

사용 조건에 **동의함(A)** 체크 후 다음을 클릭한다.
![](/assets/images/VMware/Win10/21.png){: style="width:75%;" }<br>

설치 유형은 **"사용자 지정: Windows만 설치(고급)(C)"** 를 선택한다.
![](/assets/images/VMware/Win10/22.png){: style="width:75%;" }<br>

드라이브 0 할당되지 않은 공간(50GB)을 선택하고 다음을 클릭하면 설치가 자동으로 진행된다.
![](/assets/images/VMware/Win10/23.png){: style="width:75%;" }<br>

설치가 진행되며 재부팅이 자동으로 이루어진다.
![](/assets/images/VMware/Win10/24.png){: style="width:60%;" }<br>

## 3. 초기 설정 (OOBE)

재부팅 후 초기 설정 화면이 시작된다.

지역: **한국** 선택 → 예
![](/assets/images/VMware/Win10/25.png){: style="width:75%;" }<br>

키보드 레이아웃: **Microsoft 입력기** → 예
![](/assets/images/VMware/Win10/26.png){: style="width:75%;" }<br>

두 번째 레이아웃 추가 → **건너뛰기**
![](/assets/images/VMware/Win10/27.png){: style="width:75%;" }<br>

네트워크 연결 화면에서 왼쪽 아래 **"인터넷이 없음"** 을 클릭한다.
![](/assets/images/VMware/Win10/28.png){: style="width:75%;" }<br>

**"제한된 설치로 계속"** 을 클릭해 로컬 계정으로 진행한다.

> Microsoft 계정으로 연결하면 이후 설정이 복잡해진다. 실습 환경이므로 로컬 계정으로 진행한다.

이후 개인 정보 설정 화면(위치, 진단 데이터, 수동 입력 개선, 맞춤형 환경, 광고 ID)이 연속으로 나타난다. 모두 **아니요** 를 선택하고 수락을 클릭한다.

## 4. 초기 설정

설치 완료 후 아래 항목들을 순서대로 설정한다.

4.1 컴퓨터 이름 변경

`실행(Win+R) → sysdm.cpl → 컴퓨터 이름 → 변경 → W10-1 입력 → 확인 → 닫기 → 재시작`

> 기본 이름이 랜덤 문자열로 지정되어 네트워크에서 구분이 어렵다. 구성도에 맞게 이름을 변경한다.

4.2 VMware Tools 설치

`VMware 메뉴 → VM → Reinstall VMware Tools... → 내 PC → VMware Tools 클릭 → Next → Typical → Next → Install → Finish → No`

> 클립보드 공유, 화면 해상도 자동 조정, 파일 드래그앤드롭 등 편의 기능을 사용하려면 VMware Tools 설치가 필요하다.

4.3 방화벽 - ICMP 허용

`실행(Win+R) → control → 범주 → 작은 아이콘 → Windows Defender 방화벽 → 고급 설정 → 인바운드 규칙 → 파일 및 프린터 공유(에코 요청 - ICMPv4-In) → 사용함으로 변경`

> 기본값은 ping 요청을 차단한다. 허용해야 서버에서 클라이언트로 ping 연결 테스트가 가능하다.

4.4 전원 옵션 - 절전 모드 해제

`실행(Win+R) → control → 모든 제어판 항목 → 전원 옵션 → 균형 조정(권장) 설정 변경 → 디스플레이 끄기 및 컴퓨터를 절전 모드로 설정: 해당 없음 → 변경 내용 저장`

> 실습 중 VM이 절전 모드로 전환되면 서비스 연결이 끊길 수 있다.

4.5 Windows Update 비활성화

`실행(Win+R) → services.msc → Windows Update → 일반 → 시작 유형: 사용 안 함 → 중지 → 로그온 → 계정 지정 → 찾아보기 → 고급 → 지금 찾기 → Guest → 확인 → 확인 → 암호: It1 → 확인`

> 백그라운드 업데이트가 실행되면 실습 중 재부팅되거나 성능 저하가 발생할 수 있다. Guest 계정으로 변경해서 업데이트가 실질적으로 동작하지 못하게 막는다.

4.6 IP 설정

`실행(Win+R) → ncpa.cpl → Ethernet0 우클릭 → 속성 → 인터넷 프로토콜 버전 4(TCP/IPv4)`

- IP: `10.0.0.101`
- 서브넷 마스크: `255.255.255.0`
- 기본 게이트웨이: `10.0.0.254`
- DNS: `168.126.63.1`, `8.8.8.8`
