### 1. 개요

> 이번 글에서는 Windows 11 가상머신(w11-1)을 생성하고 설치한다. <br>Windows 11은 TPM 2.0 + UEFI + Secure Boot가 필수 요구사항이라, VMware에서 Windows 11 x64를 선택하면 가상 TPM이 자동으로 추가된다. <br>w11-1 사양은 CPU 1p2c / RAM 2048MB / HDD 50GB / NAT / IP 10.0.0.201 이다.

<br>

---

<br>

### 2. 새 가상머신 생성

> Windows 10과 동일한 Custom 방식이지만, TPM 암호화와 UEFI Secure Boot 설정이 추가된다.

<br>

#### 2.1 마법사 시작

VMware 메뉴에서 **File → New Virtual Machine...** 을 클릭한다.

![](/assets/images/VMware/Win11/1.png){: style="width:40%;" }
<br>

**Custom (advanced)** 를 선택하고 Next를 클릭한다.

![](/assets/images/VMware/Win11/2.png){: style="width:55%;" }
<br>

Hardware compatibility는 기본값을 유지하고 Next를 클릭한다.

![](/assets/images/VMware/Win11/3.png){: style="width:55%;" }
<br>

Guest OS 설치 방법은 **"I will install the operating system later"** 를 선택한다.

![](/assets/images/VMware/Win11/4.png){: style="width:55%;" }
<br>

Guest OS: **Microsoft Windows**, Version: **Windows 11 x64** 를 선택한다.

![](/assets/images/VMware/Win11/5.png){: style="width:55%;" }
<br>

#### 2.2 하드웨어 설정

VM 이름을 `w11-1`로 입력하고 저장 위치를 지정한다.

![](/assets/images/VMware/Win11/6.png){: style="width:55%;" }
<br>

가상 TPM 암호화 설정 화면이 나타난다. 비밀번호를 입력하고 Next를 클릭한다.

![](/assets/images/VMware/Win11/7.png){: style="width:55%;" }

<br>

Firmware Type은 **UEFI + Secure Boot** 가 기본 선택되어 있다. 그대로 Next를 클릭한다.

![](/assets/images/VMware/Win11/8.png){: style="width:55%;" }
<br>

프로세서는 Number of processors **1**, Number of cores per processor **2** 로 설정한다.

![](/assets/images/VMware/Win11/9.png){: style="width:55%;" }
<br>

메모리는 **2048 MB** 로 설정한다.

![](/assets/images/VMware/Win11/10.png){: style="width:55%;" }
<br>

네트워크는 **Use network address translation (NAT)** 를 선택한다.

![](/assets/images/VMware/Win11/11.png){: style="width:55%;" }
<br>

I/O Controller는 **LSI Logic SAS (Recommended)** 를 선택한다.

![](/assets/images/VMware/Win11/12.png){: style="width:55%;" }
<br>

Disk Type은 **NVMe** 를 선택한다.

![](/assets/images/VMware/Win11/13.png){: style="width:55%;" }
<br>

**Create a new virtual disk** 를 선택한다.

![](/assets/images/VMware/Win11/14.png){: style="width:55%;" }
<br>

디스크 크기는 **50 GB**, **Store virtual disk as a single file** 을 선택한다.

![](/assets/images/VMware/Win11/15.png){: style="width:55%;" }
<br>

디스크 파일명은 기본값을 유지하고 Next를 클릭한다.

![](/assets/images/VMware/Win11/16.png){: style="width:55%;" }
<br>

설정을 확인하고 **Finish** 를 클릭한다.

![](/assets/images/VMware/Win11/17.png){: style="width:75%;" }

### 3. ISO 연결 및 설치

> 생성한 VM에 Windows 11 ISO를 연결하고 설치를 진행한다. 흐름은 Windows 10과 동일하다.

<br>

**Edit virtual machine settings → CD/DVD (SATA) → Use ISO image file** 에서 Windows 11 ISO 경로를 지정하고 OK → **Power on this virtual machine** 을 클릭한다.

![](/assets/images/VMware/Win11/18.png){: style="width:90%;" }
<br>

설치 언어, 시간/화폐 형식, 키보드 모두 **한국어** 로 설정하고 다음을 클릭한다.

![](/assets/images/VMware/Win11/19.png){: style="width:75%;" }
<br>

**지금 설치(I)** 를 클릭한다.

![](/assets/images/VMware/Win11/20.png){: style="width:75%;" }
<br>

운영 체제 선택에서 **Windows 11 Enterprise** 를 선택하고 다음을 클릭한다.

![](/assets/images/VMware/Win11/21.png){: style="width:75%;" }
<br>

사용 조건에 동의 체크 후 다음을 클릭한다.

![](/assets/images/VMware/Win11/22.png){: style="width:75%;" }
<br>

설치 유형은 **"사용자 지정: Windows만 설치(고급)"** 를 선택한다.

![](/assets/images/VMware/Win11/23.png){: style="width:75%;" }
<br>

드라이브 0 할당되지 않은 공간(50GB)을 선택하고 다음을 클릭한다.

![](/assets/images/VMware/Win11/24.png){: style="width:75%;" }

![](/assets/images/VMware/Win11/25.png){: style="width:60%;" }

### 5. 초기 설정

> 설치 완료 후 실습에 필요한 시스템 설정을 순서대로 진행한다. Windows 10과 동일하다.

<br>

#### 5.1 컴퓨터 이름 변경

`실행(Win+R) → sysdm.cpl → 컴퓨터 이름 → 변경 → W11-1 입력 → 확인 → 닫기 → 재시작`

- 기본 이름이 랜덤 문자열로 지정되어 네트워크에서 구분이 어렵다. 구성도에 맞게 이름을 변경한다.

<br>

#### 5.2 VMware Tools 설치

`VMware 메뉴 → VM → Reinstall VMware Tools... → 내 PC → VMware Tools 클릭 → Next → Typical → Next → Install → Finish → No`

- 클립보드 공유, 화면 해상도 자동 조정, 파일 드래그앤드롭 등 편의 기능을 사용하려면 VMware Tools 설치가 필요하다.

<br>

#### 5.3 방화벽 - ICMP 허용

`실행(Win+R) → control → 범주 → 작은 아이콘 → Windows Defender 방화벽 → 고급 설정 → 인바운드 규칙 → 파일 및 프린터 공유(에코 요청 - ICMPv4-In) → 사용함으로 변경`

- 기본값은 ping 요청을 차단한다. 허용해야 서버에서 클라이언트로 ping 연결 테스트가 가능하다.

<br>

#### 5.4 전원 옵션 - 절전 모드 해제

`실행(Win+R) → control → 모든 제어판 항목 → 전원 옵션 → 균형 조정(권장) 설정 변경 → 디스플레이 끄기 및 컴퓨터를 절전 모드로 설정: 해당 없음 → 변경 내용 저장`

- 실습 중 VM이 절전 모드로 전환되면 서비스 연결이 끊길 수 있다.

<br>

#### 5.5 Windows Update 비활성화

`실행(Win+R) → services.msc → Windows Update → 일반 → 시작 유형: 사용 안 함 → 중지 → 로그온 → 계정 지정 → 찾아보기 → 고급 → 지금 찾기 → Guest → 확인 → 확인 → 암호: It1 → 확인`

- 백그라운드 업데이트가 실행되면 실습 중 재부팅되거나 성능 저하가 발생할 수 있다. Guest 계정으로 변경해서 업데이트가 실질적으로 동작하지 못하게 막는다.

<br>

#### 5.6 IP 설정

`실행(Win+R) → ncpa.cpl → Ethernet0 우클릭 → 속성 → 인터넷 프로토콜 버전 4(TCP/IPv4)`

- IP: `10.0.0.201`
- 서브넷 마스크: `255.255.255.0`
- 기본 게이트웨이: `10.0.0.254`
- DNS: `168.126.63.1`, `8.8.8.8`
